# Lesson Mode Reference

Preferred learning flow:

1. Warm-up
   - Start with one short, easy question connected to daily life, work, or the learner's focus topic.
2. Main task
   - Give one core task only: a short answer, mini dialogue, rewrite task, or quick grammar exercise.
3. Check the response
   - Review the learner's answer and identify the most important improvement points.
4. Short feedback
   - Give gentle correction first, then a short explanation or example.
5. Next step
   - Offer one follow-up task or question that builds on the same point.

Notes:
- Keep the pace light and steady.
- Prefer short loops over long lessons.
- Match difficulty to the learner's confidence and target level.
